### 🧭 How I build apps

- **Modular by default** — every screen is a feature with its own `domain` and `presentation` module
- **MVI everywhere** — `Event → ViewModel → State`, one-off `Effect`s, no logic in the UI
- **Write once, ship everywhere** — shared Kotlin for Android, iOS, Desktop and Web
- **Reusable libraries** — anything generic moves into its own repo and gets plugged in as a submodule
